## Optional theme

`lab-theme.css` adds a responsive neon-green laboratory skin to the existing interface. To enable it, add this line inside the `<head>` of `index.html`:

```html
<link rel="stylesheet" href="lab-theme.css">
```

The stylesheet is an optional visual layer; it does not change game progress or mechanics.
